# SpriteStitcher 3.0.0-dev1

This is an early SpriteStitcher 3 development build focused on PDF pattern export improvements.

## Highlights

- Added SpriteStitcher 3 Linux build script.
- Added SpriteStitcher 3 AppImage build script.
- Added PDF export options.
- Added large-pattern tiled PDF export.
- Added cleaner default chart symbol set.
- Improved chart symbol alignment.
- Improved PDF legend sizing and padding.
- Improved pattern summary layout.
- Added direct PDF chart rendering for crisper output.
- Added PDF QA sprite for testing.

## Large-pattern PDF support

Large patterns now use a more practical tiled export mode instead of squeezing the whole pattern onto one unreadable page.

Tested with large patterns such as Woodybig.

## Known limitations

- SpriteStitcher 3 is still a development prototype.
- PDF export may still need tuning for unusual symbol/color combinations.
- UI polish is ongoing.
